# Фітнес-клуб — лабораторна робота 7

Консольний застосунок для теми №3 наскрізного проєкту з ОПАМ — «Фітнес-клуб».

## Файли проєкту

- `Program.cs` — меню, довідка про сутність «Абонемент» і дві таблиці.
- `FitnessClubLab7.csproj` — файл консольного проєкту C#.
- `.gitignore` — ігнорує службові файли та теки `bin/` і `obj/`.

## Запуск

Відкрий `FitnessClubLab7.csproj` у Visual Studio та запусти проєкт клавішею F5.
Також можна запустити з термінала командою:

```text
dotnet run --project FitnessClubLab7.csproj
```

## Пункти меню

1. Довідка про фітнес-клуб і поля абонемента.
2. Таблиця вартості абонемента за тривалістю від 1 до 5 місяців із кроком 0,5.
3. Таблиця вартості за місяцями й типами абонементів; кількість рядків і стовпців вводить користувач.
0. Вихід.

У таблицях використані навчальні тарифи: 500 грн за місяць для типу 1, далі кожен тип дорожчий на 250 грн. У першій таблиці демонструється знижка 5% для абонементів від трьох місяців.
