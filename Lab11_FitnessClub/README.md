# Фітнес-клуб — лабораторна робота 11

Це наступне оновлення наскрізного проєкту №3. До паралельних масивів абонементів додано пошук за фрагментом прізвища й діапазоном ціни, зміну полів за номером, видалення зі зсувом усіх масивів і зведення за один прохід. Попередні таблиці, демонстраційні записи та вправа з `ref`/`out` залишилися в меню.

## Запуск

Відкрийте `FitnessClub.csproj` у Visual Studio або виконайте `dotnet run --project FitnessClub.csproj`.

Продовжуйте попередній GitHub-репозиторій: перенесіть у нього файли цієї версії та зробіть щонайменше три змістовні коміти українською. Останній коміт за вимогами лабораторної: `Лабораторна 11: пошук, зміна й видалення записів`.
