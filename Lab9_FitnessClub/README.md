# Фітнес-клуб — лабораторна робота 9

Це наступне оновлення того самого проєкту. Масив `values` на 100 чисел і лічильник `count` оголошені в `Main`. Додавання, видалення, показ і статистика працюють із цим масивом через параметри; індекс і значення для нових дій Main читає та передає методам.

## Запуск

Відкрийте `FitnessClub.csproj` у Visual Studio або запустіть `dotnet run --project FitnessClub.csproj`.

Продовжуйте попередній Git-репозиторій: замініть у ньому `Program.cs` цією версією й створіть окремі змістовні коміти для змін лабораторної 9.

Для таблиць фітнес-клубу збережено методи лабораторної 8. Нові пункти меню керують спільним масивом, а демонстрація показує різницю між передаванням `int` і масиву.
