# Фітнес-клуб — лабораторна робота 10

Це наступне оновлення наскрізного проєкту №3. Абонементи зберігаються у паралельних масивах сталої місткості 100 записів. Номер призначає програма; можна додати запис із перевіркою полів, показати таблицю, завантажити шість демонстраційних записів і порахувати активні абонементи, що завершуються протягом наступних семи днів.

У меню збережено таблиці вартості з лабораторної 8 та вправу зі спільним масивом і параметрами `ref`/`out` з лабораторної 9.

## Запуск

Відкрийте `FitnessClub.csproj` у Visual Studio або виконайте `dotnet run --project FitnessClub.csproj`.
