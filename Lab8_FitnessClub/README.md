# Фітнес-клуб — лабораторна робота 8

Це наступна версія того самого консольного проєкту «Фітнес-клуб». Вона розділяє меню, довідку, табулювання, обчислення ціни та перевірку числового введення на окремі методи.

## Запуск

Відкрийте `FitnessClub.csproj` у Visual Studio або запустіть `dotnet run --project FitnessClub.csproj`.

Для продовження спільного Git-проєкту використайте цей `Program.cs` замість попереднього у вже створеному репозиторії. Новий репозиторій для лабораторної 8 не створюйте.

У табличній функції задано демонстраційний тариф 1000 грн/місяць і знижку 5% від трьох місяців. Параметри проміжку та крок читаються через `ReadDouble`; у другій таблиці межі читаються через `ReadInt`.
